WorkKB 打包使用手册

将个人工作知识库桌面应用打包为 Windows EXE 安装包的完整指南

概述

WorkKB 是基于 Tauri 2 的桌面应用，由 Rust 后端 + Vue 前端 + Python sidecar 三部分组成。打包时需要将三部分分别编译并合并为最终安装包。

打包后的安装包对终端用户零依赖——用户只需 Windows 10/11，无需安装 Python、Rust 或 Node.js。

一、打包环境要求

以下软件需安装在打包者的机器上（终端用户不需要）：

软件版本要求用途下载地址
Node.js18+前端构建 + Tauri CLInodejs.org
Rust稳定版编译 Rust 后端rustup.rs
MSVC Build ToolsVS 2022C/C++ 链接器（Rust 依赖）Visual Studio 下载页
Python3.10+打包 sidecar（PyInstaller）python.org

提示：Rust 和 MSVC 只需在打包机器上安装。安装 Rust 时选择默认选项即可，MSVC Build Tools 需勾选「使用 C++ 的桌面开发」工作负载。

二、一键打包（推荐）

项目根目录已提供 build.bat 脚本，双击或在终端运行即可：

cd "d:\Trae CN\project1\work-kb"
build.bat

脚本自动完成以下 5 个步骤：

  1. 1安装 Python 依赖（python-docx / openpyxl / python-pptx / pyinstaller）
  2. 2用 PyInstaller 将 sidecar 打包为独立 parse_server.exe
  3. 3安装前端 npm 依赖
  4. 4执行 tauri build 编译 Rust 后端（release 模式）
  5. 5将 sidecar 复制到发布目录

整个过程约 5–15 分钟，取决于机器性能。

三、手动打包步骤

如需手动执行或排查问题，按以下步骤操作：

1安装 Python 依赖

pip install -r src-tauri\sidecar\requirements.txt pyinstaller

2用 PyInstaller 打包 sidecar

cd src-tauri\sidecar
pyinstaller --onefile --name parse_server --noconfirm parse_server.py
copy dist\parse_server.exe .
rmdir /s /q dist build
del parse_server.spec
cd ..\..

说明：--onefile 将 Python 运行时 + 三个解析库全部打包进单个 exe，终端无需安装 Python。该 exe 通过 stdin/stdout 进行 JSON-RPC 通信，无需弹窗。

3安装前端依赖

npm install

4执行 Tauri 构建

npm run tauri build

此命令会依次执行：

  • npm run build — 构建前端（输出到 dist/）
  • cargo build --release — 编译 Rust 后端（输出到 src-tauri/target/release/）
  • 生成 NSIS 安装包（.exe）和 MSI 安装包（.msi）

5复制 sidecar 到发布目录

mkdir src-tauri\target\release\sidecar 2>nul
copy src-tauri\sidecar\parse_server.exe src-tauri\target\release\sidecar\

程序运行时会在自身目录下查找 sidecar\parse_server.exe，因此必须将此文件放在主程序同级目录。

四、构建产物说明

文件路径说明
主程序src-tauri\target\release\work-kb.exe独立可执行的桌面应用
Sidecarsrc-tauri\target\release\sidecar\parse_server.exeOffice 文件解析引擎

五、分发方式

方式一：安装包分发（推荐）

将 NSIS setup.exe 发给用户，用户双击安装即可。安装后程序自动出现在开始菜单。

注意：需手动将 sidecar\parse_server.exe 复制到安装目录（通常为 C:\Program Files\WorkKB\sidecar\）。

方式二：绿色版分发

将以下两个文件打包为 zip 发给用户：

work-kb.exe
sidecar\parse_server.exe

用户解压后直接双击 work-kb.exe 运行，无需安装。目录结构：

WorkKB/
├── work-kb.exe
└── sidecar/
    └── parse_server.exe

七、常见问题

Q: 安装后打开 Office 文件报错「启动 sidecar 失败」

A: 检查安装目录下是否存在 sidecar\parse_server.exe。如果没有，从打包机器的 src-tauri\sidecar\parse_server.exe 复制过去。

Q: 打包时报错「link.exe not found」

A: MSVC Build Tools 未安装或未勾选 C++ 工作负载。重新安装 VS Build Tools，勾选「使用 C++ 的桌面开发」。

Q: PyInstaller 打包出的 exe 被杀毒软件误报

A: 这是 PyInstaller 的常见问题（打包行为类似病毒注入）。可将被报毒的 parse_server.exe 加入杀毒软件白名单，或使用代码签名证书对 exe 进行签名。

Q: PDF 能解析但 Word/Excel/PPT 不能

A: PDF 由 Rust 原生解析（无需 sidecar），Office 文件由 Python sidecar 解析。如果 sidecar 缺失或损坏，只有 PDF 能正常工作。请确认 sidecar\parse_server.exe 存在且可运行。

Q: 如何修改应用图标

A: 准备一张 512x512 的 PNG 图片，执行 npx tauri icon 你的图标.png，会自动生成所有尺寸的图标文件覆盖到 src-tauri/icons/。
